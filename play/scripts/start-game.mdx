## 1. 从首页找到剧本

打开首页后，可以直接浏览剧本，也可以使用顶部的题材标签筛选。也可以在搜索框输入剧本名称，再点击剧本卡片进入详情页。

卡片上先看这几项：

- **剧本图片**：帮助你快速辨认故事；
- **剧本类型**：区分独立剧本和系列剧本；
- **游玩、喜欢、收藏数量**：了解其他玩家的互动情况；
- **作者和发布时间**：确认作品来源和更新时间。

## 2. 先看详情页

详情页会显示标题、标签、简介、作者、互动按钮和两个游玩入口。建议先读完简介，再决定从哪种方式进入：

- **开始新游戏**：从头开始一局；
- **加载存档**：继续之前保存的进度。

<Frame caption="剧本详情页">
  <img
    src="/images/player/generic-script-detail.png"
    alt="剧本详情页显示类型、发布时间、标签、简介、作者和开始游戏入口"

详情页底部的**喜欢**和**收藏**也可以在这里操作；作者区域的**关注**会进入创作者主页。它们不会替代开始游戏，想进入故事仍要点击游玩入口。

## 3. 读完故事背景

点击“开始新游戏”后，页面会先展示“故事背景”。读完后按页面提示继续，进入开场演出。

<Frame caption="开始游戏后显示的故事背景">
  <img
    src="/images/player/generic-story-background.png"
    alt="开始游戏后显示故事背景和继续阅读提示"
  />
</Frame>

故事背景用于交代人物、地点和当前问题。它不是操作说明，也不是需要填写的表单；读完后点击页面底部的继续提示即可。

## 4. 进入互动页面

开场演出结束后，就会进入可以输入内容的游戏页面。你可以选择“说话”或“行动”，也可以打开“推荐行动”寻找参考。

<Frame caption="剧本互动页面">
  <img
    src="/images/player/generic-game.png"
    alt="剧本互动页面显示故事内容、输入区、当前地点、回合和物品栏"
  />
</Frame>

页面上的区域可以这样认：

- 顶部：打开日志、查看地点、切换清爽模式或退出游戏；
- 中间：阅读当前故事内容；
- 底部：选择“说话”或“行动”，输入内容并发送；
- 右侧：查看当前角色、回合、物品和游戏菜单；
- 右侧边缘：需要灵感时打开推荐行动。

如果你之前已经开始过这局，回到详情页后选择“加载存档”，再选择要继续的存档。
