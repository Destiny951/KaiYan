## 必填项不是写作建议

各节点页里的“完成检查”是写作质量建议；真正会让**测试**和**提交送审**被拦住的是下面这些字段。缺失时不会生成可测试版本，而是列成阻碍项。

| 节点 | 无条件必填字段 |
| --- | --- |
| 剧本起点 | 剧本名称、剧本简介、剧本语言、故事背景、主角、剧本总控 |
| 幕 | 幕名称、本幕推进方向、本幕收束依据、幕内事件 |
| 角色 | 姓名、年龄 |
| 地点 | 名称 |
| 物品 | 名称 |
| 线索 | 名称 |
| 情报 | 名称、具体内容 |
| 状态组件 | 组件名称、最小值、最大值、初始值、正增长、正增长条件、负增长、负增长条件、数值区间、对玩家可见、变化提示 |
| 结局 | 结局标题 |
| 分支 | 没有单独必填字段，但每条出口都必须填写选择策略 |

### 条件必填

- 剧本起点的**系列归属**选择“加入已有系列”时，必须选择一个已有系列；选择“新建系列”时，必须填写新系列名称。两者不能同时填。
- 结局的**触发模式**选择“全局检测”时，必须填写触发条件。

## 关系检查

除了字段，编辑器还会检查节点之间的连接：

- 剧本起点必须且只能连接到一个幕；
- 每个幕要有主流程出口，所有路线最终都要能走到结局；
- 情报必须有唯一的揭露幕；
- 状态组件必须绑定唯一角色；
- 物品归属必有其一：由角色持有，或放在某一幕现场；两者都没有，或同时都有，都会拦住测试与送审；
- 同一地点上前面某一幕出现过的角色，本幕必须交代：出场写进**本幕可出场角色**，不出场写进**本幕不出场角色**；
- 填写了**开局地点**时，它必须是第一幕绑定的地点；**开场文本**里说话的角色必须出现在第一幕的**本幕可出场角色**里；
- 线索来源三选一：来自某一幕、某个角色或某件物品。

关系不对时，先调整故事结构，不要为了通过检查随意交换连接方向。完整的方向和唯一/可叠加规则见[节点连接与关系](/create/editor/connections)。

## 常见输入错误

- **标签不在平台题材内**：只能选择悬疑、仙侠、校园、西幻、爱情、职场、科幻、都市、末世、历史，最多两个；
- **年龄不是纯数字**：只能填阿拉伯数字，例如 `32`；写成 `32 岁` 或中文数字会校验失败；
- **状态数值越界**：最小值不能小于 `-1000`，最大值不能大于 `1000`，最小值必须小于最大值；
- **状态区间不连续**：数值区间必须首尾相接，并一直覆盖到最大值。

## 什么时候检查

点击**测试**并新建测试会话时，编辑器会先检查阻碍项。存在阻塞问题时不会创建会话，页面会列出问题类型和所在位置；按提示补齐后重新创建会话。**提交送审**使用同一套检查，所以最好在测试阶段就把阻碍项清干净。

图片字段不参与必填检查，但尺寸、格式和透明背景有自己的要求，见[剧本起点](/create/editor/start)、[地点](/create/editor/location)、[角色](/create/editor/character)、[物品](/create/editor/item)和[结局](/create/editor/ending)页的图片小节。
