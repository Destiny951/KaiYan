## 关系不是正文

编辑器靠节点之间的连线决定谁在哪一幕出现、物品归谁、线索从哪来。在正文里写“这封信属于林舟”不会建立关系，只有画布上对应的连线才算。写正文前先确认图上已经连好。

连线有两类：**唯一关系**在同一时刻只能有一个目标，改归属时替换旧连线；**可叠加关系**可以同时连多个目标。方向也不能为了通过检查而交换，如果创作意图不符合下面的表，先调整故事结构。

## 连接表

| 连接 | 用途 | 规则 |
| --- | --- | --- |
| 剧本起点 → 幕 | 指定起点之后进入的第一幕 | 只能有一条 |
| 幕 → 幕 / 分支 / 结局 | 本幕的主线出口 | 每幕只有一条，三选一 |
| 分支 → 幕 / 结局 | 分支的各条后续路线 | 可以有两条或更多 |
| 角色 → 幕 | 角色在这一幕出现 | 可叠加，同一角色可以连接多幕 |
| 地点 → 幕 | 这一幕发生在这个地点 | 可叠加，同一地点可以服务多幕 |
| 物品 → 角色 | 物品由该角色持有 | 二选一，与“物品 → 幕”互斥 |
| 物品 → 幕 | 物品放在这一幕现场 | 二选一，与“物品 → 角色”互斥 |
| 线索 → 幕 / 角色 / 物品 | 线索的来源 | 三选一 |
| 情报 → 幕 | 情报的揭露幕 | 只能有一个 |
| 状态组件 → 角色 | 这个状态跟踪谁 | 只能有一个，主角也可以 |

## 互斥关系怎么改

物品归属、线索来源、情报揭露幕、状态绑定角色，以及起点和幕的主线出口都属于唯一关系。要换归属时，直接用新的连线替换旧的，不要同时留下两条，也不要用“先断开再连上”来模拟替换。

角色参与多幕、地点服务多幕、分支的多条出口，以及线索、情报、物品各自关联到同一幕，这些都可以叠加，不需要互相替换。

## 常见连接错误

- 剧本起点连了多个幕，或者根本没有出口；
- 某一幕没有主线出口，路线走到一半断掉；
- 某条路线最终到不了结局；
- 情报没有揭露幕，或状态组件没有绑定角色；
- 物品同时由角色持有又放在幕里，或者线索同时来自两处；
- 正文里已经写了角色在场、物品易主，但图上没有对应连线。

连接关系、必填字段和图片规格是三类不同的检查：本页管连线，[必填项与阻碍项](/create/editor/required-fields)管字段，图片规格写在各自的节点页。
