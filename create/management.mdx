## 管理页能做什么

进入创作区后，页面顶部显示**剧本列表**和当前数量。这里是所有作品的入口：新建草稿、搜索作品、按状态筛选、继续编辑和查看已上架数据都在这里完成。

## 卡片上看什么

每张卡片通常包含：

- **封面和标题**：用来辨认作品；没有封面时会显示标题首字；
- **状态**：包括**草稿、审核中、已上架、已下架**；
- **系列或章节信息**：系列作品会显示所属系列和章节；
- **版本标签**：已上架作品显示当前版本；
- **时间**：草稿显示最近保存时间，已上架作品显示发布时间，审核中显示送审时间；
- **更多操作**：草稿可以继续编辑或删除；审核中的作品可以打开草稿；已上架作品可以选择已有版本创建新的草稿。

## 按状态找作品

状态筛选不是作品内容的修改操作，只改变列表显示：

| 筛选 | 适合什么时候用 |
| --- | --- |
| 全部 | 想看所有作品 |
| 草稿 | 继续填写或清理还没有送审的作品 |
| 审核中 | 查看已经送审、正在等待处理的作品 |
| 已上架 | 查看玩家当前可以游玩的版本和数据 |
| 已下架 | 查看暂时不在目录中的作品 |

搜索框支持按剧本名称或系列名称查询。筛选后没有卡片时，先清空搜索文字和状态筛选，不要误以为作品被删除。

## 查看已上架数据

点击已上架卡片，会从右侧打开数据面板。当前可以看到：

- 游玩人数；
- 平均游玩回合数；
- 收藏数；
- 点赞数；
- 通关数。

## 收入分成：现在与以后分开看

当前管理页没有可用的收入结算数据。未来如果平台正式开放创作者分成，管理页可以继续扩展为：

1. 收入来自哪些作品或游玩行为；
2. 当前可分成金额和已结算金额；
3. 结算周期、状态和明细；
4. 平台规则允许的提现方式。

这些内容要等平台公布正式规则后再填写。不要把“预计获得收入”当成已经到账，也不要自行按游玩人数推算收入。

## 管理页和编辑器怎么配合

- 在**草稿**卡片进入编辑器，完成字段和连线；
- 在编辑器里**保存**后回到管理页，卡片会保留最近保存时间；
- 测试通过后从编辑器**提交送审**，管理页状态变为**审核中**；
- 审核退回后回到草稿修正；
- 审核通过并上架后，从管理页查看当前版本和数据。

管理页当前没有把“提交送审”和“自动上架”合并成一个动作。
