# 开演文档

这里是开演的公开文档，按“游玩”和“创作”整理产品使用说明，支持中文和 English 切换。

“游玩”从剧本目录开始，说明如何进入故事、使用游戏页面、关注创作者、管理余额和处理问题反馈。
“创作”说明如何创建、测试、送审和管理剧本，并逐个介绍编辑器里的组件和字段。

当前截图以中文界面为准；切换到 English 后，页面文字和目录会切换，截图仍可能保留中文界面。
