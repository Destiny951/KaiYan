---
title: "Likes and Favorites"
description: "Like a script or save it to your favorites from a card or details page."
---

## Use a script card

Each script card has like and favorite icons. Select the icon you want.

<Frame caption="Chinese UI screenshot: card interaction buttons">
  <img src="/images/player/script-card-actions.png" alt="Script card with play, like, favorite counts, and script type" />
</Frame>

Likes and favorites are separate. Select an active icon again to remove that record.

## Use the details page

The details page has the same like and favorite actions. Both locations update the same record.

<Frame caption="Chinese UI screenshot: details page interactions">
  <img src="/images/player/generic-script-detail.png" alt="Script details with like, favorite, and share actions" />
</Frame>

## Find saved scripts

Open **Favorites** in your profile to find scripts you saved. This is a personal list, not a ranking by like count.
