title: "Follow Creators"
description: "Open a creator profile from a script page and follow the creators you like."
---

## Open a creator profile

From any script details page, select the creator name. The profile shows the creator’s information, follower counts, following counts, and published scripts.

<Frame caption="Chinese UI screenshot: creator profile">
  <img src="/images/player/creator-profile.png" alt="Creator profile with avatar, creator name, follower counts, following counts, and follow button" />
</Frame>

## Follow or unfollow

Select **Follow** in the profile area. The button changes to the followed state. Select it again to unfollow.

<Frame caption="Chinese UI screenshot: followed creator state">
  <img src="/images/player/creator-profile-followed.png" alt="Creator profile after the follow action is complete" />
</Frame>

Following a creator does not favorite every script they publish. Favorite an individual script from its card or details page.

## Find followed creators

Open **Following** in your profile to see the creators you follow and manage those follows.
