## Open the setting

Go to your profile and select **Settings**. The **Theme** area offers three choices.

<Frame caption="Chinese UI screenshot: theme settings">
  <img src="/images/player/profile-theme.png" alt="Profile settings with light, dark, and system theme choices" />
</Frame>

- **Light** uses a light page.
- **Dark** uses a dark page.
- **System** follows the device appearance setting.

Select an option and open another page to confirm the result. System mode is useful when your device appearance changes automatically.
