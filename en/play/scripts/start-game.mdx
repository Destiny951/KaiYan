## 1. Find a script

Browse the home page or use the topic filters. You can also search by script title and select a card.

<Frame caption="Chinese UI screenshot: script card in the catalog">
  <img src="/images/player/script-catalog-overview.png" alt="KaiYan home page with topic filters and script cards" />
</Frame>

Look at the image, script type, play count, likes, favorites, creator, and publish time before opening the details.

## 2. Read the details

The details page shows the title, tags, summary, creator, interaction buttons, and two ways to enter:

- **Start New Game** begins from the beginning.
- **Load Save** continues an existing save.

<Frame caption="Chinese UI screenshot: script details">
  <img src="/images/player/generic-script-detail.png" alt="Script details with type, publish time, tags, summary, creator, and start button" />
</Frame>

You can like or favorite the script here. Following the creator is separate from saving this script.

## 3. Read the story background

After you select **Start New Game**, the app shows the story background first.

<Frame caption="Chinese UI screenshot: story background before the first turn">
  <img src="/images/player/generic-story-background.png" alt="Story background page with a prompt to continue reading" />
</Frame>

This page introduces the people, place, and immediate problem. It is reading material, not a form or a choice.

## 4. Enter the game

After the opening, the interaction page lets you write what your character says or does. You can also open **Recommended Actions**.

<Frame caption="Chinese UI screenshot: game page">
  <img src="/images/player/generic-game.png" alt="Game page with story content, input area, current location, turn, and inventory" />
</Frame>

- The top bar opens logs, location, display mode, and exit options.
- The center shows the current story.
- The bottom input area sends speech or an action.
- The right side shows the current character, turn, inventory, and menu.

If you already started this story, return to its details and choose **Load Save**.
