## Open Invite

From your profile, select **Invite**. The page shows your own code and copy button on one side, plus invite statistics and a field for binding a friend’s code on the other.

## Invite a friend

Select **Copy Invite Code** and send the code to your friend. They bind it from their own account; never send your account password with it. Successful invite count and earned action value are result statistics, not fields you type yourself.

## Bind a friend’s code

1. Enter the other person’s code in **Friend Invite Code**.
2. Select **Confirm Bind**.
3. Follow the page message to confirm the result.

The field currently asks for a six-character code. Check it before submitting; do not repeatedly bind different codes. Hide real codes in public screenshots and tickets.
