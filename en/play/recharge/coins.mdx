## Review the packages

Open the action value page in your profile. The **Recharge Packages** area shows each package, price, and coin amount.

</Frame>

The amounts shown below were captured from a local development page. Always follow the current page:

| Package | Price | Coins |
| --- | --- | --- |
| Starter | HK$9.99 | 38 |
| Standard | HK$29.99 | 38 |
| Deep Dive | HK$59.99 | 110 |
| Immersion | HK$99.99 | 230 |

## Choose a package

Check the package name, price, and coin amount, then select **Buy Now**. Coins are not the same as action value; the two balances remain separate.

<Frame caption="Chinese UI screenshot: exchange key dialog">
  <img src="/images/player/key-redemption.png" alt="Exchange key dialog asking for an exchange key" />
</Frame>

If you have an exchange key, select **Exchange Key** and enter it in the dialog. Never place a real key in a public screenshot, ticket, or message.

<Warning>
  This page documents the entry point only. Current price, amount, payment, delivery, refund, and promotion results follow the page shown at the time of purchase.
</Warning>
